# MediCheck – Medicine Identification and Analysis Application

## About the Project
MediCheck is a web-based medicine identification and search application developed using Python and Machine Learning. It helps users identify medicines and retrieve relevant medicine information through text-based search and image-assisted identification.

## Features
- Medicine search using text input.
- Image-based text extraction using OCR.
- Medicine matching using TF-IDF and cosine similarity.
- Medicine information retrieval from structured datasets.
- Web-based interface for interacting with the application.

## Technologies Used
- Python
- Flask
- Machine Learning
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Tesseract OCR
- HTML, CSS and JavaScript
- Pandas

## Project Files
- `app.py` – Flask web application.
- `matcher.py` – Medicine matching and search functionality.
- `build_model.py` – Model-building functionality.
- `prepare_data.py` – Data preparation.
- `medicheck_cleaned.csv` – Cleaned medicine dataset.
- `MediCheck_Member3_Search_Database.csv` – Medicine search database.
- `medicine_index.pkl` – Saved medicine index.
- `tfidf_matrix.joblib` – Saved TF-IDF matrix.
- `tfidf_vectorizer.joblib` – Saved TF-IDF vectorizer.
- `templates/index.html` – Web application interface.
